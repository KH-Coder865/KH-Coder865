## Featured Projects

### [HealthLink](https://github.com/KH-Coder865/HealthLink---HMS)

Hospital-management application with a Flask and SQLAlchemy backend, versioned REST APIs, and a Vue frontend. Implements role-based workflows for appointments and treatment records.

### [ParkSense](https://github.com/KH-Coder865/ParkSense_KH)

Flask and SQLite parking-management application for administering lots and spots, handling reservations and releases, and calculating parking costs from timestamps.

### [EcoVerse](https://github.com/KH-Coder865/EcoVerse)

Flask web application for reporting and tracking environmental issues, with map and dashboard views for working with location-based reports.

### [JuriSync](https://github.com/KH-Coder865/JuriSync)

Flask application for legal case management, case and lawyer search, role-based workflows, and case-priority features.

Python analytics tool that turns natural-language business questions into structured query plans, validates them, and executes supported operations with Pandas. Uses Pydantic for plan schemas and Groq for query interpretation.
